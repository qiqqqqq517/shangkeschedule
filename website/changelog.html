v3.69.22026-09-26

无障碍读屏语义补齐

  • 修复 8 处读屏「读不出来」的操作控件：课程列表的返回 / 退出多选按钮此前只读「未加标签的按钮」；待办与日程的完成勾选框完全读不出可勾选与是否已勾选（现播报「复选框，已勾选 / 未勾选」）；设置页与课程颜色页的色块此前读「未加标签，可点击」（现播报「单选按钮，已选中 / 未选中」）。
  • 设置页分组标题、日程页「全天 / 上午 / 下午 / 晚间」标题现在支持读屏按标题跳转，长列表不再是一条平铺条目。
  • 外观页毛玻璃预览区不再对读屏暴露 —— 它只是效果演示，此前会把里面的示例课程名当成真实内容读出来。
  • 说明：界面上的装饰性图标（如与文字并列的图标）保持不播报，这是有意为之，避免读屏重复朗读同一内容。

修复稳定性与安全

  • 修复压缩包解压的路径校验缺陷：原校验用前缀匹配判断目标路径是否在解压目录内，会把同级目录（如 repo_evil）误判为目录内部，恶意构造的压缩包条目可写到目录之外。
  • 修复解压流程与 WebView 拦截的资源 / 句柄泄漏：压缩包句柄从不关闭会导致临时文件删不掉；响应流包装后不关闭会每次请求泄漏一个 HTTP 通道。
  • 修复课程表（xlsx）导入可能崩溃：对超大的行列引用加上限，避免索引越界或一次性分配海量空行导致内存耗尽；并修正在列引用非法时会静默把数据写到错误列的问题。
  • 修复 ICS 日历导入在 VALARM 块未闭合时的数组越界。
  • 修复 iOS 上「导出备份」直接崩溃（该功能在 iOS 未实现，但异常类型无法被上层捕获）。
  • 修复英文界面下「明日」日期只显示月份、丢失具体日期的问题。
