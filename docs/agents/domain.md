# 领域文档约定

仅在需要澄清领域概念、架构边界或追溯决策时读取。

- 本项目采用单一上下文：根目录 `CONTEXT.md`（术语/领域约束）与 `docs/adr/`（决策），按真实需要创建。
- 文件不存在就继续依据仓库与 IMA 工作，不把缺文档当阻塞，不为普通修改先搭文档框架。
- 只检索本次概念及相关 ADR，不批量通读全部决策；已读且未变的内容不重复读。
- 沿用已有术语。发现真实歧义或决策冲突时，明确原定义、新结论与依据，按 IMA 规则留痕。
- 通用流程引用 `AGENTS.md`、[任务路由](task-routing.md)与[开发流程](workflow.md)，本文件不重复版本、提交与验证规则。
